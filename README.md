# Advent of Code 2024 — Kotlin Solutions

A Kotlin/JVM practice workspace organized by Advent of Code day. The current source tree contains day 1 through day 8 directories and their corresponding input files.

## Layout

- `src/day01/` through `src/day08/`: separate day packages with a `main` entry point.
- `Day01.txt` and `day02.txt` through `day08.txt`: local puzzle inputs.

The early exercises explore sorting, frequency counts, sequence validation, regular-expression parsing, and grid searches.

## Run a day

Open in IntelliJ IDEA with Kotlin/JVM support, choose the day's `main` function, and set the working directory to the repository root so relative input paths resolve. There is no Gradle wrapper or unified run command.

Correctness, completion of both puzzle parts, and performance should be evaluated per day.
